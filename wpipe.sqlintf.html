Module contents

Description

Provides the tools to handle the SQL interface with the database.

How to use

This subpackage handles the interface with the SQL database for which the connection is powered by the third-party module SQLAlchemy. In practice, no one should ever need to use this subpackage, it contains the tools to initialize the database connection and query it, as well as duplicates of each of the Wpipe classes which objects are meant to represent a single row of the corresponding database table. Instead, these classes are exploited by their Wpipe counterparts to interact with the database.

Utilities

PARSER

pre-instantiated parser powered by the module argparse

SESSION

session which SQLAlchemy uses to communicate with the database

COMMIT_FLAG

boolean flag to control the automatic committing

commit

Flush and commit pending changes if COMMIT_FLAG is True

flag to control the automatic committing.
